# Interactive AI and Machine Learning

**Status:** idea saved for future development. No implementation yet.

Build an interactive learning experience for AI and machine learning, inspired by [Every Joule](https://iamtechartist.github.io/every-joule-lesson1/).

Combine concise explanations, equations and manipulable visual models. Learners predict an outcome, change parameters, observe what happens and explain the result.

## Possible lessons

- How a neuron computes an output.
- How gradient descent changes a model.
- How training data affects generalization.
- How attention connects tokens.
- How activation interventions change model behavior.

Begin with one small lesson when development starts. Select its audience, prerequisites and learning objective first.

The reference informs the teaching format and visual experience. Its code and assets are not included. See also the [teachers' notes](https://iamtechartist.github.io/every-joule-lesson1/teachers.html).
