# AI Systems and HPC

A container for independent projects in AI systems, Rust, GPU computing, and high performance computing.

| Project | Focus | Status |
| --- | --- | --- |
| [Exact Vector Search](https://github.com/AG4MA/exact-vector-search) | Exhaustive vector search, Rust, PTX, correctness, and CPU versus GPU benchmarks | Project definition |
| [Physical Signal Anomaly Detection](https://github.com/AG4MA/physical-signal-anomaly-detection) | Physical signals, datasets, model interpretation, and measured computation | Project definition |
| [Improving LLM Performance on GPUs Through Kernel Optimization](https://github.com/AG4MA/llm-gpu-kernel-optimization) | Profile LLM inference, optimize one GPU kernel, measure total performance, and evaluate a Rust host | Project definition |
| [Open GPU Computing in Rust](open-gpu-computing-in-rust/) | Contribute to portable Rust compute tools, starting with a small upstream change | Planned contribution project |
| [Open Ascend Backend in Rust](open-ascend-backend-in-rust/) | A portable Rust interface and a bounded Huawei Ascend runtime backend | Project brief; Ascend validation pending |

Implemented projects have their own public repositories. New directions begin here as English project briefs before implementation and repository setup.
