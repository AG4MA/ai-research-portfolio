# Radio and Electronics

A container for practical radio, electronics and instrumentation projects, combining purchased components with original builds and documented measurements.

| Project | Focus | Status |
| --- | --- | --- |
| [Desktop Radio Lab](https://github.com/AG4MA/desktop-radio-lab) | Build a desktop amateur radio station from first reception to authorized contacts, including original antennas, electronics and controls | Project definition and build roadmap |

Projects are maintained in independent repositories. Physical results are reported only after assembly and measurement.
